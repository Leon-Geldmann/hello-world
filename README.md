## 💰 价格转换器 Chrome 扩展

这个项目包含一个Chrome浏览器扩展，可以在网页中的商品价格下方自动添加以黄金和比特币计价的等值价格。

### 主要功能
- ✨ 自动检测网页中的价格（支持多种货币）
- 💰 显示比特币和黄金等值价格
- 🔄 每分钟自动更新一次
- 🎨 精美的UI设计

### 快速开始
1. 用浏览器打开 `generate-icons.html` 下载图标
2. 将图标保存到 `icons/` 文件夹
3. 在Chrome中访问 `chrome://extensions/`
4. 开启"开发者模式"并加载扩展

详细说明请查看 [EXTENSION_README.md](EXTENSION_README.md)
